# Project Index

## English

This document provides a central index of all projects within Engineering Design Journey.

Projects are organized into three tracks:

- RE — Reverse Engineering & Design Analysis
- ED — Electronic Design from Scratch
- MD — Medical Device Engineering & Analysis

Each project will receive a unique ID when it is officially selected and added to the portfolio. The same ID will be used consistently across GitHub documentation, LinkedIn posts, YouTube videos, and Instagram content.

### Project Status Definitions

- Planned: Selected for future work but not yet started.
- In Progress: Analysis, design, or documentation is underway.
- On Hold: Work has been temporarily paused.
- Completed: The planned project scope has been completed and documented.
- Published: The project has been presented publicly through the relevant channels.

### Project List

No projects have been officially registered yet.

Projects will be added here once their scope, ID, and initial plan have been agreed upon.

## Türkçe

Bu belge, Engineering Design Journey kapsamındaki tüm projelerin merkezi listesini sunar.

Projeler üç çalışma alanına ayrılır:

- RE — Tersine Mühendislik ve Tasarım Analizi
- ED — Sıfırdan Elektronik Tasarım
- MD — Tıbbi Cihaz Mühendisliği ve Analizi

Her projeye, portföye resmî olarak seçilip eklendiğinde benzersiz bir kimlik verilecektir. Aynı kimlik; GitHub dokümantasyonunda, LinkedIn gönderilerinde, YouTube videolarında ve Instagram içeriklerinde tutarlı bir şekilde kullanılacaktır.

### Proje Durumları

- Planned (Planlandı): Gelecekte yapılmak üzere seçildi ancak henüz başlanmadı.
- In Progress (Devam Ediyor): Analiz, tasarım veya dokümantasyon çalışmaları sürüyor.
- On Hold (Beklemede): Çalışmaya geçici olarak ara verildi.
- Completed (Tamamlandı): Planlanan kapsam tamamlandı ve belgelendi.
- Published (Yayımlandı): Proje ilgili kanallarda kamuya açık olarak paylaşıldı.

### Proje Listesi

Henüz resmî olarak kaydedilmiş bir proje bulunmamaktadır.

Projeler; kapsamları, kimlikleri ve başlangıç planları üzerinde anlaşmaya varıldıktan sonra buraya eklenecektir.
