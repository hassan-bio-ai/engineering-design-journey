# Project Index

## English

This document provides a central index of projects within Engineering Design Journey.

Projects are organized into three tracks:

- **RE** — Reverse Engineering & Design Analysis
- **ED** — Electronic Design from Scratch
- **MD** — Medical Device Engineering & Analysis

Each officially registered project receives a unique ID. The same ID is used consistently across GitHub documentation, LinkedIn posts, YouTube videos, and Instagram content.

### Project Status Definitions

- **Planned:** Approved for future work but not yet started.
- **In Progress:** Analysis, design, or documentation is underway.
- **On Hold:** Work has been temporarily paused.
- **Completed:** The planned project scope has been completed and documented.
- **Published:** The project has been publicly presented through the relevant channels.

### Project Registration and Documentation

Each project will have its own directory containing a project overview, references, engineering calculations, simulation files, test documentation, results, and related deliverables as applicable.

Project IDs must remain consistent across all project files and associated publications.

Project scope and technical requirements must be defined before detailed implementation begins. Analytical findings, simulation results, and physical test results must be clearly distinguished.

## Türkçe

Bu belge, Engineering Design Journey kapsamındaki projelerin merkezi listesini sunar.

Projeler üç çalışma alanına ayrılır:

- **RE** — Tersine Mühendislik ve Tasarım Analizi
- **ED** — Sıfırdan Elektronik Tasarım
- **MD** — Tıbbi Cihaz Mühendisliği ve Analizi

Portföye resmî olarak kaydedilen her projeye benzersiz bir kimlik verilir. Aynı kimlik; GitHub dokümantasyonunda, LinkedIn gönderilerinde, YouTube videolarında ve Instagram içeriklerinde tutarlı biçimde kullanılır.

### Proje Durumları

- **Planned (Planlandı):** Gelecekte gerçekleştirilmek üzere onaylandı ancak henüz başlanmadı.
- **In Progress (Devam Ediyor):** Analiz, tasarım veya dokümantasyon çalışmaları sürüyor.
- **On Hold (Beklemede):** Çalışmaya geçici olarak ara verildi.
- **Completed (Tamamlandı):** Planlanan proje kapsamı tamamlandı ve belgelendi.
- **Published (Yayımlandı):** Proje ilgili kanallarda kamuya açık olarak paylaşıldı.
