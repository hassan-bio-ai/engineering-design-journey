Adapt the following structure to the needs of the project:

- `docs/` — Technical documentation and project notes
- `references/` — Reference material and source links
- `design/` — Schematics, PCB files, CAD files, or other design assets
- `calculations/` — Engineering calculations and analysis
- `simulation/` — Simulation files and results
- `tests/` — Test procedures, measurements, and experimental results
- `images/` — Original diagrams, screenshots, and project figures

Only create folders that are relevant to the specific project.
