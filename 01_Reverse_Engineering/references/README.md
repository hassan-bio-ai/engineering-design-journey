# Reverse Engineering — References

This directory stores or documents the reference materials used in Reverse Engineering & Design Analysis projects.

## Purpose

The purpose of this directory is to keep technical sources organized, traceable, and easy to access throughout the engineering investigation.

## Types of References

- **Datasheets:** Component specifications, electrical characteristics, and operating limits.
- **Reference Designs:** Original design files and documentation published by manufacturers.
- **Application Notes:** Technical explanations, design recommendations, and implementation examples.
- **Technical Manuals:** Operating principles, configuration details, and troubleshooting guidance.
- **Standards and Publications:** Relevant technical standards, research papers, and engineering publications.

## File Organization

When permitted and practical, store project-specific reference files in a dedicated subdirectory.

For example:

- `datasheets/` — Component datasheets
- `reference_designs/` — Original reference design documents
- `application_notes/` — Manufacturer application notes
- `standards/` — Relevant standards and technical publications

Create only the subdirectories required by the project.

## Source and Usage Guidelines

- Prefer official manufacturer websites and primary technical sources.
- Record the original URL and document title.
- Verify the document revision and publication date when relevant.
- Respect copyright, licensing, and redistribution restrictions.
- Link to restricted or copyrighted materials instead of uploading unauthorized copies.
- Distinguish original manufacturer documentation from independent analysis.

### Referans Türleri

- **Veri Sayfaları:** Bileşen özellikleri, elektriksel karakteristikler ve çalışma sınırları.
- **Referans Tasarımlar:** Üreticiler tarafından yayımlanan özgün tasarım dosyaları ve dokümantasyon.
- **Uygulama Notları:** Teknik açıklamalar, tasarım önerileri ve uygulama örnekleri.
- **Teknik Kılavuzlar:** Çalışma prensipleri, yapılandırma ayrıntıları ve sorun giderme bilgileri.
- **Standartlar ve Yayınlar:** İlgili teknik standartlar, araştırma makaleleri ve mühendislik yayınları.

### Dosya Düzeni

### Kaynak ve Kullanım İlkeleri

- Üreticilerin resmî web sitelerini ve birincil teknik kaynakları tercih edin.
- Orijinal URL'yi ve belge başlığını kaydedin.
- Gerektiğinde belge sürümünü ve yayın tarihini kontrol edin.
- Telif hakkı, lisans ve yeniden dağıtım kısıtlamalarına uyun.
- Kısıtlı veya telif hakkıyla korunan belgeleri izinsiz yüklemek yerine bağlantılarını ekleyin.
- Üreticinin özgün dokümantasyonu ile bağımsız mühendislik analizini birbirinden ayırın.
