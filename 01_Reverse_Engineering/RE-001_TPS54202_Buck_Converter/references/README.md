# References

## Purpose

This directory contains the technical sources and reference documents used in the RE-001 project.

All sources should be recorded clearly so that engineering decisions and conclusions can be traced back to reliable documentation.

## Reference Materials

The following materials may be included:

- Official component datasheets.
- Manufacturer reference designs and application notes.
- Evaluation module schematics and design files.
- Component documentation and technical manuals.
- Relevant technical articles and standards, where applicable.

## Source Documentation

For each reference, record:

- Document title.
- Manufacturer or publisher.
- Document revision or publication date, if available.
- Official URL or source location.
- Purpose and relevance to the project.

## Source Reliability

Official manufacturer documentation should be prioritized whenever available.

Third-party sources may be used as supplementary material, but their origin and reliability must be considered.

# Referanslar

## Amaç

Bu klasör, RE-001 projesinde kullanılan teknik kaynakları ve referans dokümanlarını içerir.

Mühendislik kararlarının ve sonuçlarının güvenilir belgelere dayandırılabilmesi için tüm kaynaklar açık ve düzenli biçimde kaydedilmelidir.

## Referans Materyalleri

Bu klasörde aşağıdaki materyaller bulunabilir:

- Resmî bileşen veri sayfaları.
- Üretici referans tasarımları ve uygulama notları.
- Değerlendirme modülü şemaları ve tasarım dosyaları.
- Bileşen dokümantasyonu ve teknik kılavuzlar.
- Gerektiğinde ilgili teknik makaleler ve standartlar.

## Kaynak Dokümantasyonu

Her kaynak için aşağıdaki bilgiler kaydedilmelidir:

- Doküman başlığı.
- Üretici veya yayıncı.
- Varsa doküman revizyonu veya yayın tarihi.
- Resmî URL veya kaynak konumu.
- Projeyle ilişkisi ve kullanım amacı.

## Kaynak Güvenilirliği

Mümkün olduğunda üreticinin resmî dokümantasyonuna öncelik verilmelidir.

Üçüncü taraf kaynakları destekleyici bilgi olarak kullanılabilir; ancak kaynakları ve güvenilirlikleri değerlendirilmelidir.
